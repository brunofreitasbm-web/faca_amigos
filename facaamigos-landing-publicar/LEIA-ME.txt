FaçaAmigos — Pacote de publicação da Landing Page (/playground)
================================================================

O QUE É ISSO
-------------
Site institucional: FaçaAmigos — Playground Inclusivo (Parque Shopping Belém)
URL final: https://institutofacaamigos.com.br/playground/

COMO PUBLICAR
--------------
1. Faça upload de TODOS os arquivos e pastas deste pacote para a mesma pasta
   do servidor/host que corresponde a "institutofacaamigos.com.br/playground/".
   - Mantenha a estrutura de pastas exatamente como está (a pasta "img/" tem
     que ficar dentro da mesma pasta do index.html).
2. Confirme que os seguintes arquivos ficam acessíveis publicamente
   (abra cada URL no navegador para testar):
   - https://institutofacaamigos.com.br/playground/
   - https://institutofacaamigos.com.br/playground/robots.txt
   - https://institutofacaamigos.com.br/playground/sitemap.xml
   - https://institutofacaamigos.com.br/playground/google877c2b37d3c979fb.html
     (esse arquivo é de verificação do Google Search Console — não mexer no
     conteúdo dele, ele precisa ficar exatamente como está)
3. Se o host tiver algum cache/CDN (Cloudflare, cache do cPanel, etc.),
   limpe o cache depois do upload para garantir que a versão nova entre no ar.

CONTEÚDO DO PACOTE
--------------------
- index.html              → página principal (HTML, CSS e JS já embutidos)
- robots.txt               → instrui buscadores a indexar o site e aponta o sitemap
- sitemap.xml               → mapa do site para o Google Search Console
- google877c2b37d3c979fb.html → arquivo de verificação de propriedade do Google
- img/                       → imagens usadas na página (fotos do espaço, equipe, etc.)
