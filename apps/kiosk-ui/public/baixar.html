Instalador para Windows

Aplicativo de gestão do balcão (PDV, check-in e ponto). Sempre a versão mais recente.

Baixar instalador (.exe)

Windows 64 bits · cerca de 105 MB

Como instalar

  1. Baixe o arquivo e execute-o.
  2. Aceite o aviso de permissão do Windows (necessário para liberar o acesso dos tablets na rede da loja).
  3. Depois de instalado, o app se atualiza sozinho.
