Inline label for status, categories, or metadata. Always pill-shaped. Two modes: translucent (default) and solid.

```jsx
<Badge variant="pink">Inclusivo</Badge>
<Badge variant="teal">Aberto</Badge>
<Badge variant="solid_pink">Novo</Badge>
<Badge variant="neutral">Em breve</Badge>
```

Use translucent variants on dark backgrounds; solid variants for higher-contrast situations.
