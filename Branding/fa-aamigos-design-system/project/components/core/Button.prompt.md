Use for any primary or secondary call-to-action. All buttons are fully rounded (pill). Never use sharp corners.

```jsx
<Button variant="primary" size="md">Entrar</Button>
<Button variant="teal" size="lg" fullWidth>Ver Horários</Button>
<Button variant="secondary" size="sm">Saiba mais</Button>
<Button variant="ghost">Cancelar</Button>
<Button disabled>Indisponível</Button>
```

Variants: primary (pink), teal, secondary (outline), ghost (transparent), amber, dark.
Sizes: sm (36px tall), md (44px), lg (52px).
Press: scale(0.96). Hover: scale(1.02) + colored glow shadow.
